# XB 小红书 / Bilibili 封面

一个 Skill，按用户选择的平台创建属于用户自己的封面。用户的个人照片决定人物身份，用户选择的风格决定配色、字体、背景及插画语言。手绘贴纸风只是可选方案。

## 开始与平台选择

1. 开始先索要：“请提供你本人的照片，以及想要的封面风格（文字描述或参考图均可）。”已提供的部分不重复询问；“直接生成”不能替代缺少的照片和风格输入。
2. 从当前请求识别平台；未指定时再问做小红书、B 站还是两种。同帖跨平台改版继承当前用户已确认的照片、风格和准确标题。
3. 确认主题、准确标题与换行，以及截图、流程或 Logo 等内容素材。逐步确认人物位置、占比与版式，每次推进一个关键决定。
4. 卡通分身为可选项，只有用户选择后才根据该用户本人照片创建。总结构图后生成；已授权直接生成时不重复确认。

## 按平台读取规则

- **小红书**：读取 [xiaohongshu.md](references/xiaohongshu.md)。3:4，建议 1080×1440。按需使用人物搭配流程、截图或 Logo 的竖版布局。
- **B 站 / Bilibili**：读取 [bilibili.md](references/bilibili.md)。默认 16:9，建议 1920×1080；需要时制作 4:3，建议 1440×1080。截图对比必须保持身份、缩放和标签准确。
- **同时制作或跨平台转换**：读取两份平台规则，分别重排，不能只裁切或补边。以上为设计建议，不冒充平台强制规格。
- 选用手绘贴纸风时，按需读取 [visual-system.md](references/visual-system.md)。其他风格优先服从用户选择，不强制套用贴纸配色或非像素限制。

## 身份、素材与输出

- 不包含、读取、展示或复用作者的真人照片和卡通形象，不自动查找本机或相邻 Skill 的私人照片库。
- 仅使用当前用户提供或明确指定的照片；风格参考中的人物不作为身份来源。缺少照片时先索要，不用他人或虚构人物代替。
- 不自动保存用户照片、索引或使用历史。长期保存需用户明确要求并指定位置。
- 保留照片中的脸、发型、服装和真实手势，不凭空补画手、眼镜或道具。截图和 Logo 使用真实源素材，不生成假品牌或无依据的结果数字。
- 使用可用图片生成或编辑工具。要求像素保真时优先原图合成；生成工具可能改变人物和界面，不能把 AI 重绘称作无损抠图。无法满足时说明限制。
- 生成后检查实际比例、标题、人物脸手、截图身份、文字安全区、风格与可选分身。针对失败项最多修正两次，仍失败则说明限制并保留可审阅结果。
- 最终提供图片和保存位置，如实说明是生成合成还是原图合成。路径遵循用户约定，不明确时先问。
