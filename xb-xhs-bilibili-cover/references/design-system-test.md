# 双截图横版通用案例

此案例只说明布局，不附带作者照片、卡通角色或原始图片。使用时先索要当前用户本人照片及想要的风格，再替换全部占位内容。

- 标题：使用用户确认的准确标题及换行。
- 真人：使用用户提供的照片，根据真实姿态安排位置，不预设长相、服装或手势。
- 截图：由用户确认原图和结果图的身份，标签跟随对应图片。
- 起稿：标题在顶部，双截图在左侧，用户照片在右侧；需按实际素材重排。
- 配色与装饰服从用户选择；结果 Tag 只使用用户确认且有依据的文案，不预填还原度。
- 卡通分身仅在用户选择时加入，必须基于该用户本人照片。
- 生成式工具可能改变界面和人物细节，不能当作原图无损合成。
